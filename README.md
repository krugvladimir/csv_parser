# 📊 CSV → JSON Parser — преврати таблицу в структуру данных за секунду

> «CSV — это просто, JSON — это удобно»

**CSV Parser Pro** — это набор консольных утилит для парсинга CSV-файлов и экспорта данных в JSON-формат.  
Программа автоматически определяет разделитель, обрабатывает заголовки, конвертирует типы данных и сохраняет результат.

## 🚀 Особенности
- 🧠 Автоопределение разделителя (запятая, точка с запятой, табуляция).
- 📋 Умная обработка заголовков: первая строка → ключи JSON.
- 🔄 Преобразование типов: числа, булевы значения, null.
- 📦 Поддержка вложенных структур (через точечную нотацию в заголовках, например `user.name`).
- 💾 Сохранение результата в JSON-файл или вывод в консоль.
- 🔍 Фильтрация строк по условию (где реализовано).
- 📈 Поддержка больших файлов (потоковая обработка).
- 🎨 Цветной вывод в терминале и прогресс-бар.

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости.

| Язык       | Зависимости              | Команда запуска                         |
|------------|--------------------------|-----------------------------------------|
| Python     | стандартная библиотека   | `python csv_parser.py input.csv`        |
| Go         | стандартная библиотека   | `go run csv_parser.go input.csv`        |
| JavaScript | Node.js, никаких         | `node csv_parser.js input.csv`          |
| Java       | стандартная библиотека   | `javac csv_parser.java && java csv_parser input.csv` |
| C#         | .NET (или mono)          | `dotnet run input.csv`                  |
| Rust       | `csv`, `serde`, `serde_json` | `cargo run -- input.csv`            |
| Ruby       | `csv` (стандартная)      | `ruby csv_parser.rb input.csv`          |
| PHP        | стандартная библиотека   | `php csv_parser.php input.csv`          |

> По умолчанию результат сохраняется в `output.json` в той же папке.

## 📖 Пример использования

**Входной CSV (`data.csv`):**
```csv
id,name,age,active,salary
1,Alice,30,true,55000.50
2,Bob,25,false,48000.00
3,Charlie,35,true,72000.00
Команда:

bash
$ python csv_parser.py data.csv
Результат (output.json):

json

  {"id": 2, "name": "Bob", "age": 25, "active": false, "salary": 48000.0},

]
